Magic Damage

⚠ Design only — nothing here is built. Your R190-E ruling holds until you rule on this.

You said the Ra column is a magic attack, that auras may be too, and that magic could be "a whole different spectrum". This page lists every strike in the game, shows three ways magic could work on the one stat ladder, and works the numbers through so you can see what each option does before you pick.

1 The problem

Your ruling R190-E: a drafted ATK pick buffs physical melee and ranged hits only — not boss skills, not Helga. That ruling already treats some hits as "not physical", but the game has no word for them and no rule for how they are defended. Before anything is built, the word needs a meaning.

Every number on this page comes from the one stat ladder — none is a bespoke number:

pool   = HP × (1 + 0.2 × DEF) × 5 = HP × (5 + DEF)  fifths
damage = ATK × (1 + 0.2 × PEN) × 5 = ATK × (5 + PEN) fifths
structure pool = n × (5 + n)  — n connectors is both its HP and its DEF

Two things the inventory shows that matter for the design

Finding 1

There are already two DEF models

A unit's DEF sits inside its pool (HP × (5 + DEF)). It never reduces a hit — it only makes the health bar longer.

The keep's bought DEF works the other way: it divides each hit by (5 + DEF) / 5.

They are the same ladder multiplier, applied at a different end.

Finding 2

Today an HP pick and a DEF pick are the same pick — and so are ATK and PEN

A draft pick adds +10 % (compounded per pick) to the whole pool (HP/DEF picks) or the whole strike (ATK/PEN picks). It never moves the DEF or PEN stat itself.

So any magic rule that treats DEF or PEN specially inherits this: until a DEF pick actually raises DEF, "magic ignores DEF" cannot tell an HP-drafted unit from a DEF-drafted one.

2 Three things "magic" could mean

All three stay on the one ladder. None adds a bespoke number. Under every option, no ATK/PEN pick ever buffs magic (R190-E).

OPTION 1

A label, nothing else

What the game does today, made explicit.

Every strike is marked physical or magic. The only rule: ATK/PEN picks never buff magic. Magic is defended exactly like physical.

OPTION 2

Magic ignores DEF

A magic hit lands as if the target's DEF were 0.

Against a unit, the hit is scaled up by (5 + DEF) / 5 (rounded down, never below 1). Against a building, its DEF (= connector count) likewise. Against the keep, its bought DEF does not reduce it.

OPTION 3 · RECOMMENDED

A magic resist stat — RES

A fifth stat on the same ladder.

Physical hits are defended by DEF (as now), magic hits by RES. Still one health bar: the magic hit is scaled by (5 + DEF) / (5 + RES), rounded down, min 1.

RES starts equal to DEF for every unit, tower and keep, so the factor is 1 and day one plays exactly like today. From then on DEF and RES are separate levers.

How the three relate
Option 3's factor is (5 + DEF) / (5 + RES). Set RES = DEF and you get Option 1 (factor 1). Set RES = 0 and you get Option 2 (factor (5 + DEF) / 5). Option 3 is a dial between the other two, set per unit.

Shapes and the keep

  • A shape inside a structure is not targetable, but area damage uses its 70 (14 HP / 0 DEF).
  • A lone built shape or a stink bag: pool 5 (1 HP / 0 DEF) — anything one-hits it.
  • The keep is the one deliberate exception to the ladder. Its bought DEF cuts every hit: hit × 5 / (5 + DEF level).

6 What each option does — side by side

OPTION 1 · LABEL

In play

  • Nothing changes. Every fight plays as today.
  • The words are right: the game knows which hits are magic.
  • R190-E keeps doing what it does.

To build

  • A tag on every strike in the attackers table.
  • One test that fails if a strike has no tag.
  • No multiplayer version bump.
OPTION 2 · IGNORE DEF

In play

  • One Ra column kills every tier-9 boss.
  • The Pharaoh's ritual one-shots enemy bosses; WRATH three times a fight.
  • High-DEF units (the Pharaoh at 16, the Kraken and Warlord at 12) lose most of their toughness to magic.
  • The keep's bought DEF stops nothing magic.

To build

  • Everything in Option 1, plus the scaling rule on units, buildings and the keep.
  • Every Ra / aura test that counts kills re-pinned.
  • Multiplayer version bump.
OPTION 3 · RES STAT

In play

  • Day one: identical to today (RES = DEF, factor 1). No boss becomes one-shot.
  • After that: a DEF pick for physical, a RES pick for magic.
  • Races can lean one way — tough against swords, soft against spells, or the reverse.

To build

  • Option 2's rule with RES in place of 0.
  • A RES value on every unit and tower (default = DEF).
  • A keep RES purchase, a draft choice, a character-card row.
  • A version bump if RES can ever differ per unit (a drafted RES).
The draft, under every option (R190-E)
As built, an ATK/PEN pick reaches every unit strike — melee, ranged, and the three unit "explosions" (suicide goblin, drone, Voltkin chain; drafted since S190). It reaches no skill, aura, tower, keep or raid. That stays true under all three options: no ATK/PEN pick ever buffs magic. What would buff magic is Q3.

7 Questions for you

Q1Which attacks are magic?
Recommendation

magic = a skill or an aura: the Ra columns (the Pharaoh's, and POWER / WRATH OF RA), the zombie boss's rot, SCORCHED GROUND, the stink tower's aura.

physical = anything a unit, a tower, the keep or a player swings, shoots or blows up: melee, arrows, the castle gun, the laser, Helga, the stink bags, the suicide goblin, the drone, the Voltkin, a raid.

Q2What should magic do differently?
Recommendation

Option 3 (a RES stat that starts equal to DEF) if you want it to be "a whole different spectrum" — it changes nothing on day one and opens a new draft choice.

Say no to Option 2 as it stands: one Ra column would kill every boss in the game.

If you only want the words right for now, Option 1 costs nothing and is what R190-E already does.

Q3What makes magic stronger, if not an ATK pick?
Recommendation

Nothing new yet. WRATH OF RA already triples POWER OF RA's casts. A "spell power" draft pick can come once the Q1 list is settled and you have played with it. Under Option 3, the matching defence pick — RES — would come first.

Q4The three lightning / explosion units — drone, Voltkin chain lightning, suicide goblin — physical or magic?
Recommendation

Physical, as built. They are a unit's own attack, and your S190 draft-ATK ruling already buffs them; calling them magic would take that buff back. Same answer for the lightning hub's self-destruct — ruled at 4 × a drone, so it follows the drone.

Q5Should magic go through the keep's bought DEF?
Recommendation

Follow Q2. Option 1: the keep's DEF stops magic like anything else (today's rule). Option 3: the keep gets a RES that starts at its bought DEF, and a separate button to buy more.

Build sizing (not a plan)

  • Option 1: a DamageClass beside DamageSource (damage.ts:115), one argument at every caller above, a call-sites test (the S183 damage.callSites.test.ts pattern over every damageEntity / damageConnector / applyRadialDamage caller). No wire, no hash, no protocol bump.
  • Option 2: Option 1 + the scale factor inside damageEntity / damageConnector and the keep's arm; a shared rule both peers compute → protocol bump; re-pin every Ra / aura kill-count test.
  • Option 3: Option 2's factor with RES in place of 0 + a res stat on every creature config (default = def), the keep's RES purchase, a draft axis, the character-card row. A drafted RES is a per-creature wide field (factory + serialize + hash + worker) → protocol bump.
