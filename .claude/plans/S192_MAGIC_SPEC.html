1 · The rule, in one line

A magic hit lands as hit × (5 + DEF) ÷ (5 + MRES), rounded down, never below 1. A physical hit lands exactly as today.

Why: on our ladder DEF isn't taken off the hit — it makes the health bar longer (HP × (5 + DEF)). So against magic, the same bar has to act as if it were HP × (5 + MRES) long. Scaling the magic hit by that ratio does exactly that. HP cancels out, so it works for every unit.

pool = HP × (1 + 0.2 × DEF) × 5 ← physical hits use up this bar magic = HP × (1 + 0.2 × MRES) × 5 ← magic hits "see" this one — same bar, rescaled hit damage = ATK × (1 + 0.2 × PEN) × 5 ← unchanged

The one wrinkle: one-point burns

Rot, Scorched Ground and the stink aura tick one point at a time. "Round down, never below 1" would make every tick 1 whatever the MRES — so MRES would do nothing against four of the six magic attacks. Instead, a burn tick is spread over its own beats: a unit with more MRES simply gets skipped on some beats. Exact on average, no randomness, and identical to today when MRES = DEF. ⚠ mine — the only place a magic tick can be 0 (a slower burn, never immunity).

5 · Multiplayer

Magic resistance for units is worked out from the unit's type (and, for castle soldiers, the owner's race, which is already sent). The new castle MRES button and its level do go over the network, and both sides must run the same rule. So this needs a protocol version bump when it merges: an old build can't play a new one. The RESIST pop-up is worked out on each screen and sends nothing.
