What changes, in one picture

Today every effect is a flat, solid shape. After the upgrade, effects are soft particles drawn with additive light (they brighten whatever is under them), with one bloom pass and a ground shockwave on the High setting.

today: a solid 3.4 px dot
after: a soft additive mote with a hot core and bloom

Art versus code

Stays generated art (veo or atlas)

All characters, towers, castles, damage-ramp sheets, the corpse-eater feed rows, and the Ra strike sheet. You preferred your art there, so code only adds glow around it.

Moves to code effects

Every aura, siphon, beam, bolt, blast, cloud, glow, telegraph polish and racial-perk visual. No more veo clips for effects: a clip costs about $20 and cannot react to the game. A code effect costs a few KiB and looks the same on every screen.

Not yet

Skeletal animation (Spine, DragonBones), as you said. Archived mechanics (seagulls, potato, bombs, rainbow) are excluded.

Rules every effect follows

The same on every screen

Every effect is re-derived each frame from synced state, with a seeded random keyed by entity id and tick. Nothing goes on the wire, no protocol bump.

Fast at a wave-5 fight

Pooled sprites. Bloom and shockwave run only on High. Measured at 120 creatures before and after.

Easy to compare

Add ?fx=legacy to the URL to see the old version of every rebuilt effect.

Free

pixi-filters (MIT, which you approved). Textures are drawn in code, so there are no downloads and no licences.
